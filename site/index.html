Green liveness only proves the pipeline is moving; chain-truth checks ask whether indexed bytes match the program IDL, on-chain state, and produced slots.

Integrity flow

Wire checks after decode in your indexer pipeline. Exit 0 only if every step is Pass.

  1. Indexer Decoded accounts & slot writes
  2. →
  3. Shape IDL length & discriminator Pass
  4. →
  5. Reconcile Bytes vs chain (slot-lag window) Pass
  6. →
  7. Completeness Indexed slots vs getBlocks Pass
  8. →
  9. Process exit 0 iff all Pass

Why this exists

A Kamino Lend indexer ingested empty payloads for Obligation and UserMetadata accounts for 158.91 hours while every liveness signal stayed green: checkpoints advanced, freshness looked fine, rows kept arriving. Nothing asked whether the data had the right shape.

CLI checks

Flags below match karat --help and subcommand help on this repo.

karat shape

Check an observed account payload against the Kamino account registry, by discriminator and exact size.

  • --account-type <ACCOUNT_TYPE>
  • --len <LEN>
  • --json (global)

karat reconcile

Diff indexed bytes against on-chain state via getMultipleAccounts. Exits non-zero unless every account is Pass — Fail and Skipped (including slot-lag) both fail the process.

  • --rpc-url <RPC_URL> (env: KARAT_RPC_URL)
  • --account <ACCOUNTS> (repeatable)
  • --indexed-base64 <INDEXED_BASE64> (repeatable)
  • --indexed-slot <INDEXED_SLOTS> (optional)
  • --max-slot-lag <MAX_SLOT_LAG> (default 32)
  • --json (global)

karat completeness

Compare indexed slots to getBlocks for a window. Leader skip-slots omitted by getBlocks are not gaps.

  • --rpc-url <RPC_URL> (env: KARAT_RPC_URL)
  • --start <START>
  • --end <END>
  • --slot <SLOT> (repeatable)
  • --slots <SLOTS> (comma-separated)
  • --json (global)

Global: --json, -h / --help, -V / --version

Deploy & CI

Default CI runs cargo fmt, cargo clippy -D warnings, and cargo test --all — no RPC. Live checks stay opt-in via KARAT_RPC_URL or --rpc-url.

GitHub Pages (one-time): in the repo go to Settings → Pages, set Source to GitHub Actions. Pushes to main run .github/workflows/pages.yml and publish the site/ folder.

Copy this workflow to run an offline shape check without a local Rust install:

name: Shape check (offline)

on:
  push:
    branches: [main]
  pull_request:

jobs:
  shape:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - name: Offline shape check (no RPC)
        run: cargo run --release --bin karat -- shape --account-type UserMetadata --len 1032

Or start from .github/workflows/shape-check.example.yml in the repo (workflow_dispatch only; no RPC).
