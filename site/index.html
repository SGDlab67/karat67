Deploy the check

Offline shape gate in CI — no RPC, no secrets. Copy into your workflow, or start from .github/workflows/shape-check.example.yml. 

name: Shape check (offline)

on:
  push:
    branches: [main]
  pull_request:

jobs:
  shape:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - name: Offline shape check (no RPC)
        run: cargo run --release --bin karat -- shape --account-type UserMetadata --len 1032

Live reconcile/completeness stay opt-in via KARAT_RPC_URL. This site does not host an RPC service.
